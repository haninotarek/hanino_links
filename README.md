## ✨ About

A single-page **link-in-bio** that puts all my links in one beautiful place —
built with pure HTML, CSS & JavaScript. No frameworks, no build step, just open it.

🔗 **Live:** https://haninotarek.github.io/hanino_links/

## 🎨 Features

- 🌗 **Light & Dark mode** — auto-detects the visitor's system, with a manual toggle (remembered per visitor)
- 🌐 **English / العربية** toggle with full **RTL** support
- 📱 Fully **responsive** — mobile, tablet & desktop
- 💫 Smooth **micro-interactions** (hover, shine, staggered reveal, rotating logo ring)
- ♿ Accessible: keyboard focus states & reduced-motion support
